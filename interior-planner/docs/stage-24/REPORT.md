# Этап 24: прогулка по квартире

Дата: 27.11.2026. Машина: ноутбук Intel Core 7 150U, встроенная графика Intel, Windows 10 Pro; Chrome 158 и Edge 158.
Скрипт: `node scripts/capture-stage24.mjs chrome|msedge` (нужен `npm run dev`). Сцена: схема 2 комн. 55 м² (кухня-гостиная, прихожая, спальня, санузел). В кухне-гостиной стоят диван, журнальный стол и торшер, на полу паркет, одна стена покрашена; в спальне кровать и ковролин.

## Что сделано

| Подпункт | Реализация |
|---|---|
| 24.1 | Кнопка «Прогулка по квартире» над 3D. Сцена открывается на всё окно, игрок встаёт в свободную точку активной комнаты, взгляд — вдоль длинной стороны. Камера на высоте глаз 160 см. W A S D и стрелки — шаг 140 см/с, Shift — 280 см/с; шаг считается по времени кадра (не больше 0,1 с на кадр). Обзор мышью: щелчок захватывает указатель, без захвата — перетаскивание. Подсказка, имя комнаты игрока и кнопка «Выйти из прогулки» — в углу. `src/scene3d/WalkScene.tsx` |
| 24.2 | Вся квартира в 3D: полы с покрытиями, потолки, каждая стена один раз с отделкой обеих сторон, окна со стеклом и рамой, светильники и мебель всех комнат. Межкомнатные проёмы без створок; входная дверь закрыта. Пол, стены и окна строятся теми же компонентами, что и вид комнаты (`src/scene3d/RoomParts.tsx`, вынесены из `RoomScene.tsx`). |
| 24.3 | Модель движения без Three.js — `src/domain/walk.ts`. Игрок — квадрат 36 × 36 см. Препятствия: блоки стен ниже пояса (простенки и подоконники; перемычка над дверью не мешает), закрытая входная дверь и коллайдеры мебели в диапазоне высот тела. Ковры и предметы над головой не мешают. Движение по x и z раздельно — вдоль стены игрок скользит; длинный шаг дробится, чтобы не проскочить стену. |
| 24.4 | В сцене 4 точечных источника. В прогулке каждый кадр берутся ближайшие к игроку включённые источники всех комнат (`nearestLightSources`), остальные включённые светятся плафоном или абажуром. Внешний мир виден через окна всех комнат (та же маска трафарета, этап 20). Выключатель в прогулке — для комнаты, где стоит игрок. |
| 24.5 | Выход: кнопка или Esc (при захвате указателя первый Esc освобождает мышь). Редактор возвращается в ту же активную комнату; в прогулке горячие клавиши редактора отключены, проект и история не меняются. |
| 24.6 | `npm run check` — без ошибок. Unit- и e2e-тесты не писались (D-23); поведение проверено скриптом в Chrome и Edge. |

## Снимки

`walk-start.png` — вход в кухне-гостиной; `walk-hall.png`, `walk-s1.png`, `walk-bath.png` — после прохода через двери в прихожую, спальню и санузел; `walk-day.png` — кухня-гостиная днём; `walk-evening.png` — 19:00; `walk-night.png` — 23:00, свет во всех комнатах и торшер; `editor-after-exit.png` — редактор после выхода.

| Ошибки страницы и ответы ≥ 400 | нет | нет |

В одном из первых прогонов в Chrome было 52 кадр/с днём; после исправления устаревшего признака `__walk` в проверке повторные прогоны в Chrome и Edge дали 60. Сырые данные — `measure-chrome.json`, `measure-msedge.json`. Замер сделан на ноутбуке, а не на эталонном ПК (см. 19.6).

Регрессия: `capture-stage21.mjs` после выноса пула источников — выключатели, люстра, сохранение при переходах и 60 кадр/с без изменений.

## Ограничения

- Этап 22 (увеличенные схемы) не выполнен; прогулка от размеров схем не зависит.
- Столкновение — по прямоугольнику в плане; ступеней и подъёма на предметы нет.
- Потолку добавлен рассеянный подсвет по силе дневного света: отражённого освещения в интерактивном виде нет.
- Тени дают только солнце и луна; тени ламп не строятся (21.3).
