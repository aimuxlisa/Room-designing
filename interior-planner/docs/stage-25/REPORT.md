# Этап 25: современный тёмный дизайн

Дата: 27.11.2026. Машина: ноутбук Intel Core 7 150U, Windows 10 Pro; Chrome 158 и Edge 158.
Скрипт: `node scripts/capture-stage25.mjs before|after chrome|msedge` (нужен `npm run dev`): снимки семи экранов при 1280×720 и 1920×1080, проверка контраста всех видимых надписей, горизонтальной прокрутки и видимого фокуса при обходе клавишей Tab. Снимки — `before/` и `after/`.

Основа темы была введена на этапе 2 (D-13, D-19); этап 25 — доводка и сверка всех экранов, включая новые панели этапов 20–24.

## Что сделано

| Подпункт | Реализация |
|---|---|
| 25.1 | `src/ui/theme.css` переписан как система оформления: переменные поверхностей (`--surface-3`, `--overlay`, `--scene-bg`, `--border-strong`), акцента (`--accent-hover`, `--accent-soft`), радиусов, тени панелей, отступов (`--space-1…5`), размеров шрифта (`--fs-xs…xl`) и длительности переходов. Одно правило кнопки на всё приложение с состояниями наведения, нажатия, выбора (`aria-pressed`/`aria-checked`), отключения и фокуса; контексты меняют только размер. До этого стиль кнопки был повторён в 11 местах с расхождениями (например, отключённая основная кнопка «Применить» была полупрозрачно-синей). Общие стили полей ввода и ползунка, тонкие тёмные полосы прокрутки, отключение переходов при `prefers-reduced-motion`. Новые цвета внесены в `themeTokens.ts`, фон 3D-сцен берётся оттуда же. |
| 25.2 | Мастер: активный шаг выделен акцентным номером; карточки схем — радиус 10 px и подсветка при наведении; одинаковые кнопки и поля на трёх экранах. Снимки `*-1-params`, `*-2-schemes`, `*-3-setup`. |
| 25.3 | Интерьер: панели поверх 3D (переходы, время суток, выключатели, прогулка, ошибки загрузки) — единая полупрозрачная поверхность с размытием фона и тенью; кнопка прогулки выделена акцентом. Панель плана при 1280×720 больше не ломает подписи кнопок на две строки — кнопки в строку, «Изменить размеры и проёмы» переносится целиком. Заголовки групп каталога — капителью; образцы отделки разнесены, чтобы рамка выбора не наезжала на подпись группы. Снимки `*-4-interior`, `*-5-finish`, `*-6-evening-apartment`, `*-7-walk`. |
| 25.4 | План: подписи комнат и размеров получили обводку цветом фона — читаются поверх стен, дуг дверей и мебели (раньше «750 см × 200 см» в прихожей перечёркивалось полотном двери); наведение на комнату и предмет подсвечивает их. Фон 3D — переменная `--scene-bg` / `themeTokens.sceneBg`. |
| 25.5 | Матрица этапа 18 (`capture-stage18-compat.mjs`): Chrome и Edge, 1920×1080, 2560×1440, 1600×900, 1366×768, 1280×720 и режим без 3D — 12 из 12, прокрутки страницы нет. Клавиатура (`capture-stage18-input.mjs`) — все проверки ok, фокус виден. |
| 25.6 | `npm run check` — без ошибок; существующий модульный тест темы (`tests/unit/theme.test.ts`, контраст и совпадение значений с theme.css) — 17 из 17. Новые тесты не писались (D-23). |

## Ограничения

- Шрифт — системный (Segoe UI Variable / Segoe UI), без загрузки файлов шрифтов.
