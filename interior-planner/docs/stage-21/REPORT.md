# Этап 21: искусственный свет

Дата: 27.11.2026. Машина: ноутбук Intel Core 7 150U, встроенная графика Intel, Windows 10 Pro; Chrome 158 и Edge 158.
Скрипт: `node scripts/capture-stage21.mjs chrome|msedge` (нужен `npm run dev`). Сцена: схема 2 комн. 55 м², кухня-гостиная, 23:00. В комнате диван, кресло, журнальный стол, ковёр, торшер и приставной столик с настольной лампой; в последнем кадре добавлена люстра.

## Что сделано

| Подпункт | Реализация |
|---|---|
| 21.1 | В каждой комнате есть стандартный плафон в центре потолка (`src/scene3d/RoomLights.tsx`) и выключатель комнаты: кнопка «Потолочный свет: вкл/выкл» поверх 3D (`src/ui/LightControl.tsx`). Состояние хранится в `uiStore.lights`: это часть вида, а не проекта, в историю отмены оно не входит и сохраняется при переходах между комнатами. |
| 21.2 | Светильники в каталоге: торшер (`floor_lamp`) и бра (`wall_sconce`) — собственные модели, сделаны на этапе 13; добавлена собственная настольная лампа с абажуром (`table_lamp`, установка на столешницу, превью `public/previews/table_lamp.jpg`, строка в ASSETS.md). Правила установки — общие правила мебели (D-05): торшер ставится на пол, лампа на столешницу, бра на стену. Прежняя настольная лампа Poly Haven (CC0) осталась в каталоге. |
| 21.3 | Модель источников — `src/domain/lighting.ts`. Одновременно освещают сцену не больше `MAX_ACTIVE_LIGHTS = 4` источников, потолочные — первыми; остальные включённые только светятся, и интерфейс об этом сообщает. В сцене всегда стоят 4 точечных источника, у выключенных сила 0: при переключении число источников не меняется, поэтому шейдеры не перекомпилируются. Тени от ламп не строятся: тень точечного источника — это 6 дополнительных проходов. Тени дают солнце и луна. |
| 21.4 | У каждого светильника свой выключатель: кнопка «‹Название›: вкл/выкл» появляется, когда выбран светильник. Включённый плафон и абажуры собственных моделей светятся; у моделей Poly Haven видно тёплое ядро в точке излучения. Свет ложится на стены, пол и мебель. |
| 21.5 | Отложено вместе с «Качественным снимком» (D-09). |
| 21.6 | Люстры есть в каталоге с этапа 13: «Люстра», «Люстра классическая», «Люстра большая», «Люстра-фонарь», а также подвесные светильники; они ставятся на потолок по общим правилам. Если в комнате есть потолочный светильник из каталога, стандартный плафон скрывается, выключатель называется «Люстра» и включает её свет (D-14). Каждая люстра занимает один из 4 источников. |
| 21.7 | `npm run check` — без ошибок. Unit- и e2e-тесты не писались (D-23); поведение проверено скриптом в Chrome и Edge. |

## Снимки (одна камера, 23:00)

- `night-all-off.png` — всё выключено, комнату освещает только луна;
- `night-ceiling-on.png` — включён потолочный свет, плафон светится;
- `night-lamps-on.png` — включены торшер и настольная лампа, абажуры светятся, свет падает на стены и мебель;
- `night-all-on.png` — всё включено;
- `evening-all-on.png` — то же в 19:00;
- `night-chandelier-on.png` — люстра вместо плафона, выключатель «Люстра: вкл».

## Проверки скриптом

| Проверка | Chrome | Edge |
|---|---|---|
| Выключатель комнаты и лампы сохраняются при переходе в другую комнату и обратно; другая комната остаётся выключенной | да | да |
| Кнопка выбранного светильника | «Торшер: вкл» | «Торшер: вкл» |
| С люстрой стандартный плафон скрыт, у люстры есть свой источник, кнопка — «Люстра: вкл» | да | да |
| История отмены не изменилась | да | да |
| Кадры при трёх включённых источниках, кадр/с (порог D-08 ≥ 60) | 59,8 | 60,2 |
| Время кадра, 95-й процентиль (порог ≤ 20 мс) | 17,3 мс | 18,0 мс |
| Кадры при переключении света каждые 10 кадров | 59,9 / p95 17,3 мс | 59,9 / p95 18,0 мс |
| Ресурсы GPU до и после переключений (геометрии / текстуры / программы) | 38 / 24 / 17 → без изменений | 36 / 24 / 15 → 38 / 24 / 17 |
| Ошибки страницы и ответы ≥ 400 | нет | нет |

В Edge до замера был выбран торшер, поэтому в его прогоне в первых кадрах впервые появились контур выбора и кольцо поворота (+2 геометрии, +2 программы). Повторные переключения ресурсов не добавляют: в Chrome, где они уже были созданы, числа не менялись.

Сырые данные — `measure-chrome.json`, `measure-msedge.json`. Замер сделан на ноутбуке, а не на эталонном ПК (см. 19.6).

## Ограничения

- Тени от ламп не строятся (21.3).
- Освещают комнату не больше 4 включённых источников.
- Сила света подобрана по виду, а не по паспортным люменам.
