# Отчёт по Этапу 22: «Квартиры чуть больше» (SPEC D-15)

## 1. Цели и задачи
- **Увеличение схем на 21 % по площади**: оси комнат всех 9 стартовых схем увеличены в 1,1 раза по каждой стороне (`LAYOUT_SCALE = 1.1`).
- **Сохранение неизменных параметров**:
  - Толщина стен: 30 см (наружные), 10 см (внутренние).
  - Размеры дверей: 80 см (межкомнатные), 70 см (санузлы), 90 см (входная дверь).
  - Размеры окон: 120 × 140 см, подоконник 90 см.
  - Высота потолка: ровно 270 см.
- **Сверка площадей со SPEC §3.1**:
  - 1А: 36,4 м²
  - 1Б: 49,3 м²
  - 1В: 53,2 м²
  - 2А: 64,1 м²
  - 2Б: 74,8 м²
  - 2В: 80,8 м²
  - 3А: 89,6 м²
  - 3Б: 100,3 м²
  - 3В: 108,4 м²
- **Ранжирование схем**: проверка выбора оптимальной схемы для площадей 36, 52, 72, 90, 108 м².
