# Этап 23: покрытия пола

Дата: 27.11.2026. Машина: ноутбук Intel Core 7 150U, встроенная графика Intel, Windows 10 Pro; Chrome 158 и Edge 158.
Скрипт: `node scripts/capture-stage23.mjs chrome|msedge` (нужен `npm run dev`). Сцена: схема 2 комн. 55 м², кухня-гостиная, диван, журнальный стол, торшер.

Подпункты 23.1–23.3 сделаны раньше, вместе с отделкой стен (этап 12, D-25). На этапе 23 закрыт 23.5: покрытие проверено целиком в Chrome и Edge. 23.4 отложен вместе с «Качественным снимком» (D-09). Этап 22 (увеличенные схемы) не выполнялся: этап 23 начат по прямой просьбе пользователя, а от размеров комнат покрытие не зависит — повтор текстуры считается от фактического размера пола.
