# Этап 18.3 — замеры скорости, памяти и повторных переходов

Дата: 27.11.2026. Скрипт: `node scripts/measure-stage18.mjs`, сырые данные — `measure.json`, кадр сцены — `measure-scene.png`.

## Оборудование

| | |
|---|---|
| Процессор | Intel Core 7 150U (ноутбук) |
| Графика | встроенная Intel Graphics 0xA7AC, ANGLE / Direct3D 11 |
| Память | 16 ГБ |
| ОС | Windows 11 (10.0.26200) |
| Браузер | Chrome через Playwright, окно 1920×1080, частота обновления 60 Гц |

Это не эталонный ПК D-08 (GTX 1660 SUPER, Xeon E3-1270) и не записанный рабочий ПК (i5-10400, GTX 1050 Ti). Встроенная графика слабее обеих, поэтому результат — нижняя оценка; окончательная проверка порогов (AC-14) — на эталонном ПК.

## Условия

- Production-сборка (`vite build`) с хуками замеров: `VITE_PROBE=1 npx vite build --outDir dist-probe`, `npx vite preview --outDir dist-probe --port 4180`. Обычная сборка хуков не содержит (`src/app/probe.ts`).
- Каждый прогон — новый контекст браузера без кеша; 3 прогона, в таблице медиана.
- Сцена: схема 2 комн. 55 м², кухня-гостиная 6,05 × 4,95 м; отделка (обои, две краски, паркет) и 20 предметов, поставленных переносом с проверкой: диван, кресло, журнальный стол, ковёр, тумба и плоский ТВ, торшер, люстра, холодильник, мойка, обеденный стол и стул, приставной столик, полки-витрина, два растения, пуф, ваза, книги, каминные часы. На кадре — 167 вызовов отрисовки, ≈ 868 тыс. треугольников.

Частота кадров ограничена обновлением экрана (60 Гц): p95 = 16,9 мс означает, что кадры не пропускаются, но запас производительности этим способом не измеряется. Единичные долгие кадры (до 67–100 мс) — в первом прогоне, при первой компиляции шейдеров.

## Память и повторные переходы

40 переходов между кухней-гостиной и другими комнатами, затем сборка мусора:

| | До переходов | После |
|---|---|---|
| Куча JS | 40–48 МБ | 33–34 МБ |
| Геометрии WebGL | 75 | 65 |
| Текстуры WebGL | 61 | 61 |

Рост памяти не обнаружен: геометрии другой комнаты освобождаются, текстуры общие и не дублируются.

## Эталонный ПК (AC-14) — задача 19.6, SPEC D-27

На эталонном ПК в папке `interior-planner`:

1. `$env:VITE_PROBE='1'; npx vite build --outDir dist-probe`
2. `npx vite preview --outDir dist-probe --port 4180`
3. `node scripts/measure-stage18.mjs http://localhost:4180/ chrome` и `... msedge`

Результаты — `docs/stage-18/measure.json` и `measure-msedge.json`; сравнить с таблицей порогов выше.
