# Планировщик квартиры

Требования: Node.js 22.12+ (проверено на 22.16.0), npm, системные Google Chrome и Microsoft Edge (для браузерных проверок).
Документы проекта: `../PRD-interior-planner.md`, `../SPEC.md`, `../Tasks.md`.

Все команды выполняются в папке `interior-planner` (здесь лежит package.json):

| Действие | Команда |
|---|---|
| Установка зависимостей по lock-файлу | `npm ci` |
| Запуск для разработки (http://localhost:5173) | `npm run dev` |
| Проверка типов | `npm run typecheck` |
| Модульные тесты (Vitest) | `npm test` |
| Браузерные проверки (Playwright, Chrome и Edge) | `npm run e2e -- --workers=1` |
| Сборка | `npm run build` |

Стек: React 19.3, TypeScript 7.0, Vite 8.3, Three.js 0.187, React Three Fiber 9.8, Drei 10.7, Zustand 5.1, Vitest 5.1, Playwright 1.65.

Повторяемые сценарии с проверками (нужен запущенный `npm run dev`): `node scripts/capture-stage15-full.mjs` — полный сценарий схем 1, 2 и 3 комнат (AC-01–AC-16); `node scripts/measure-stage18.mjs` — замеры D-08 (порядок — `docs/stage-18/REPORT.md`).

## Состояние и известные ограничения (27.11.2026)

Приёмка — `docs/stage-19/ACCEPTANCE.md`. Работает: стартовый сценарий 1/2/3 комнаты → площадь → схема → настройка размеров и проёмов → интерьер; 2D-план и 3D-вид одной комнаты с общими данными; каталог из 101 предмета (Poly Haven CC0 и собственные модели, `ASSETS.md`); перенос, поворот и проверки размещения; отделка стен и пол; отмена и повтор (Ctrl+Z, Ctrl+Y).

Не реализовано или отложено:

- проект не сохраняется между сессиями: после закрытия или перезагрузки вкладки квартира теряется (вне объёма первой версии, SPEC §2);
- финальный рендер и «Качественный снимок» отложены (D-09, этап 17);
- увеличенные схемы (22) ещё не сделаны;
- замеры скорости выполнены только на ноутбуке со встроенной графикой; проверка на эталонном ПК (GTX 1660 SUPER) — задача 19.6;
- нужен браузер с WebGL 2; без него вместо 3D показывается сообщение, план и каталог работают;
- сборка — один файл JS около 1,4 МБ (Vite предупреждает о размере, на работу не влияет).
